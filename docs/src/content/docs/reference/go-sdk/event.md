`event` is the shape every event in this system takes on the wire. That is a
CloudEvents 1.0 envelope, the origin it came from, the class that decides how
it is queued, and the cursor a reader resumes from. Nothing here is
pluggable, which is why it lives where a third party can import it and assert
against it.

A module reads envelopes off a [`busapi`](./busapi.md) window; a sink gets
them as an [`eventsapi`](./eventsapi.md) `Fact`; a history adapter stores the
same members. All of them decode into `Envelope`, check it with `Validate`,
and branch on `Type`, whose core values are the `Type...` constants. `Class`
tells a reader what to do with a type it has never seen. Telemetry is
conflated and never replayed, state and audit are kept in order, and only a
command carries a TTL. `Origin` is a resource kind and an instance id, and it
renders the same way in the source URN, the subject and a cursor. `Data`
stays raw, because its schema belongs to whoever emitted it.

The data members of the core command and transfer frames are typed here too,
so a reader decodes `CommandSettled` rather than a map.

```go
package shelf

import (
	"encoding/json"
	"log"

	"github.com/prusa3d/prusa-connect/sdk/event"
)

// handle reads one encoded envelope off a subscription window, checks it,
// and acts on the two types this module cares about.
func handle(raw json.RawMessage) error {
	var e event.Envelope
	if err := json.Unmarshal(raw, &e); err != nil {
		return err
	}

	if err := e.Validate(); err != nil {
		return err
	}

	_, origin, err := event.ParseSourceURN(e.Source)
	if err != nil {
		return err
	}

	switch e.Type {
	case event.TypeDeviceCommandSettled:
		var settled event.CommandSettled
		if err := json.Unmarshal(e.Data, &settled); err != nil {
			return err
		}

		log.Printf("%s: %s %s after %d ms", origin.ID(), settled.Verb, settled.Status, settled.ElapsedMS)
	case event.TypePrinterDeparted:
		log.Printf("%s left", origin.ID())
	}

	return nil
}
```

`Envelope` is the decode type. A relay that unmarshals into it and marshals
the result back deletes every attribute this build predates and invalidates
any signature. To forward, use `ForwardBytes` on the bytes that arrived.

### `CommandSettled` {#event-commandsettled}

type CommandSettled struct {
    // CommandID joins this frame to the requested one, and is repeated in the
    // envelope's causation id.
    CommandID string `json:"command_id"`
    // Verb is the capability key that was invoked.
    Verb string `json:"verb"`
    // Status is one of the Command status constants.
    Status string `json:"status"`
    // OutcomeUnknown says the host never observed how the command ended: the
    // caller went away, a deadline fired, the device lost its connection
    // after the frame was written, or the host restarted.
    OutcomeUnknown bool `json:"outcome_unknown,omitempty"`
    // OK is the printer's answer, and is meaningless when OutcomeUnknown is
    // set.
    OK bool `json:"ok,omitempty"`
    // MachineReason is the printer's own word for a refusal, truncated to the
    // host's bound.
    MachineReason string `json:"machine_reason,omitempty"`
    // Ignored and Substituted are what the printer did differently.
    Ignored     []string          `json:"ignored,omitempty"`
    Substituted map[string]string `json:"substituted,omitempty"`
    // FaultCode is the registered code of the refusal, empty when the command
    // did not fail with one.
