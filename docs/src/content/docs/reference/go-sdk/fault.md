`fault` is the error taxonomy every surface shares. One value carries a
registered code, the params a client interpolates, an English message, a
retry hint and a trace id. It renders as RFC 9457 `problem+json` over HTTP,
as `data.error` inside an event, and as the error on a printer command
result. A code means the same thing on all three.

An extension gets a domain of its own with `NewDomain`, a dotted lowercase
name it owns. `NewDomain` refuses the core namespace, so an extension's code
cannot collide with the server's, and a log line says who owns a failure.
Each code is registered once, in a package variable or an `init` function,
with the documentation `Document` takes. That is what went wrong, what the
caller does, whether a retry can succeed, whether the detail may leave the
process, and the params the message uses. The error reference is generated
from that registry. A caller branches with `HasCode`, which survives
wrapping, and never on message text.

```go
package acmeshelf

import (
	"fmt"
	"net/http"

	"github.com/prusa3d/prusa-connect/sdk/fault"
)

// shelf is the domain this module's codes live under. NewDomain refuses the
// core namespace, so a code here cannot collide with the server's.
var shelf = func() fault.Domain {
	domain, err := fault.NewDomain("com.github.aux.acme.shelf")
	if err != nil {
		panic(err)
	}

	return domain
}()

// SpoolEmpty is registered once, at package init, with the documentation the
// error reference publishes. A missing sentence is a refused registration.
var SpoolEmpty = fault.Register(shelf, "SPOOL_EMPTY", http.StatusConflict, fault.Document(
	"The spool in that slot is empty",
	"Load a spool into the slot and send the command again.",
	fault.RetryAllowed,
	fault.ShowDetail,
	"slot",
))

// checkSlot answers a fault the caller renders as problem+json, with the slot
// as a param a client's own translation can place.
func checkSlot(slot int, grams float64) error {
	if grams > 0 {
		return nil
	}

	return SpoolEmpty.New(fmt.Sprintf("slot %d reports 0 g", slot)).
		With(fault.IntParam("slot", int64(slot)))
}

// isEmptySpool is how a caller branches: on the code, through any wrapping.
func isEmptySpool(err error) bool {
	return fault.HasCode(err, SpoolEmpty.Code())
}
```

`Register` panics on a rejected registration, which is why it belongs at
package init; `TryRegister` is for anything later. A param the code does not
declare is dropped from every rendering and named in `Error()` only, so a
response cannot contradict the published reference.

## `fault` {#fault}

```go
import "github.com/prusa3d/prusa-connect/sdk/fault"
```

Package fault is the error taxonomy every surface shares. A Fault has a registered code, the params a client interpolates, an English message, a retry hint and a trace id. It renders as RFC 9457 problem+json for HTTP, as an event envelope's data.error and as the error of a printer command result.

The server never translates. The English message is always sent, except for a code registered as redacted, which sends its title only.

Codes are namespaced domain/REASON. NewDomain refuses the core namespace, so an extension's codes cannot collide with the core's.
