Code generated by make generate-slots from the slot table in sdk/manifest. DO NOT EDIT.

A module declares a `ui.contributes` block in its manifest. The block may only register into the slots on this page. A slot the manifest does not name is closed to it.

Every slot sits on one screen, in one area of that screen, and takes one of four forms: a page, a section, an action or a card. The form decides what the manifest entry looks like and what the bundle registers for it.

An entry of a printer slot may also carry `devices: { resident: true }` to show only on the printer this server runs on. See [Limiting an entry to the printer the server runs on](../writing-a-module.md#limiting-an-entry-to-the-printer-the-server-runs-on).

## The app: the sidebar and a page of its own

| slot | area | what the bundle registers | what it is handed | where |
| --- | --- | --- | --- | --- |
| `page` | `page` | a component | nothing | A whole screen with a route of its own, and an entry in the sidebar unless it is hidden. |

`page`

```yaml
pages:
  - path: my-page
    title: My page
    icon: blocks
    hidden: false
```

## A dashboard, the home page among them

| slot | area | what the bundle registers | what it is handed | where |
| --- | --- | --- | --- | --- |
| `dashboard-card` | `grid` | a component, and an editor if a schema cannot express its settings | its checked settings as `config`, a person's heading as `title`, its size as `size`, and `editing` | A card a person places on a dashboard, sized on its grid and drawn with the settings the person chose. |

`dashboard-card`

```yaml
cards:
  - id: my-dashboard-card
    title: My dashboard card
    description: What the card shows, in one sentence.
    icon: blocks
    size: { w: 4, h: 3 }
    least: { w: 2, h: 2 }
    settings:
      - key: device
        kind: printer
        label: Printer
```

## Adding a slot

- **New slot on an existing screen**: add a row to the table in `sdk/manifest/slots.go` and run `make generate-slots`. Then place the outlet the failing test names, write the slot's own scaffold template, and add its branch to the scaffold's locales template. The scaffold's README and changelog templates need no edit: they read the slot table.
- **New screen**: add a `Screen` constant and its rows. Add a `Subject` if the screen hands a new kind of id. Add the screen's render function to the outlet test's `Record<Screen, ...>`.
- **New form**: add the Go entry type, the TS registration type, the registry and outlet branch, and the template. The generator refuses a form it does not know.
